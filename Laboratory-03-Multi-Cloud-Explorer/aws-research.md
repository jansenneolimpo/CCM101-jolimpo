# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides a wide range of on-demand infrastructure and application services. Organizations can use AWS to build, deploy, and manage applications without having to maintain all of the physical infrastructure themselves.

## Global Infrastructure

AWS operates a global infrastructure made up of Regions and Availability Zones. This infrastructure allows organizations to deploy applications in different geographic locations and design systems for high availability and reliability.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. It allows users to create resources, configure services, monitor environments, and manage their cloud infrastructure.

## Four Core Services

### 1. Amazon EC2
Amazon Elastic Compute Cloud (EC2) provides scalable virtual servers for running applications.

### 2. Amazon S3
Amazon Simple Storage Service (S3) provides scalable object storage for storing and retrieving data.

### 3. Amazon RDS
Amazon Relational Database Service (RDS) makes it easier to set up, operate, and scale relational databases.

### 4. Amazon VPC
Amazon Virtual Private Cloud (VPC) allows users to create an isolated virtual network for AWS resources.

## Three Advantages

1. **Scalability** – AWS resources can be increased or decreased according to application requirements.
2. **Global Availability** – AWS provides infrastructure in many geographic locations around the world.
3. **Wide Service Selection** – AWS offers many services for computing, storage, databases, networking, security, and other cloud needs.

## Typical Enterprise Use Cases

AWS can be used by enterprises for web and mobile applications, data storage and backup, database hosting, business applications, analytics, and large-scale application infrastructure.
